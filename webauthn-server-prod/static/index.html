Production WebAuthn — Глава 41.02

Сервер на Rust: webauthn-rs + ciborium + sqlx (SQLite) + tower-sessions. Открывайте http://localhost:3030.

1. Регистрация passkey

Настоящая проверка attestation через webauthn-rs. Плюс ручной парсинг attestationObject через ciborium — покажем, что внутри: fmt, aaguid, credentialIdLength, COSE-ключ.

—

2. Вход с passkey

Криптографическая проверка подписи через webauthn-rs::finish_passkey_authentication. Если подпись неверна — сервер вернёт ошибку, а не ok: true.

—

3. Что нового по сравнению с главой 41.01

  • Attestation парсится через CBOR — в ответе видно fmt, aaguid, длину credential_id, сводку COSE-ключа.
  • Подпись assertion проверяется криптографически — если подделать signature, сервер отклонит вход.
  • Пользователи и passkeys в SQLite — файл webauthn.db переживёт перезапуск сервера.
  • Сессии серверные — состояние церемонии живёт в БД (ceremonies), а не в cookie.
